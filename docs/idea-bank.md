# Idea bank (warm-up only; adapt to the announced theme)

Pick the theme first. Each of these is "trigger -> agent -> action":

| Idea | Trigger | Agent does | Action |
|---|---|---|---|
| Email triage | New email | Classify urgency, draft reply | Label + Slack alert + draft |
| Meeting notes -> tasks | Notes posted | Extract action items + owners | Create Trello/Jira/Notion tasks |
| Support ticket router | New form/ticket | Categorise, find similar | Assign + notify team |
| Student deadline assistant | Classroom/Calendar update | Summarise what's due | Reminder in chat + calendar block |
| Expense/receipt logger | Receipt email | Extract amount/vendor | Append to Google Sheet |
| GitHub issue helper | New issue | Label, suggest owner | Comment + project board |
| Content repurposer | New blog/post | Summarise per channel | Draft posts for each platform |
| Lead qualifier | New signup | Enrich + score | CRM entry + owner notification |

## Scoring your idea (30 seconds)
- [ ] Works with 2-3 connectors we can access today
- [ ] Demo-able in 3 minutes without luck
- [ ] An agent makes a real decision (not just a fixed script)
- [ ] Buildable by 2 people in ~12 hours
